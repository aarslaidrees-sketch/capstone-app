# Project Instructions

## Project
Capstone app for the Frontend AI Engineering course.

## Tech Stack
- Next.js with the App Router
- React
- TypeScript
- Tailwind CSS

## Conventions
- Use TypeScript for application code.
- Use Server Components by default.
- Use Client Components only when browser APIs or interactivity are required.
- Use the existing project structure and reusable components.
- Keep the interface responsive on mobile and desktop.
- Follow accessibility best practices.
- Keep code simple, readable, and maintainable.
- Never commit secrets or environment variables.

## Validation
- Run the available lint and build checks before committing changes.
- Test affected routes after making changes.
